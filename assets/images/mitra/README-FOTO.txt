FOLDER FOTO MITRA dWarna Laundry
================================
Tiap file JPG di sini sekarang adalah gambar CONTOH / PLACEHOLDER.
GANTI setiap file menggunakan foto asli mitra dengan nama yang sama:
  hero.jpg       : foto utama, rekomendasi landscape 1600x800
  reguler.jpg    : foto layanan Reguler (800x600)
  express.jpg    : foto layanan Express (800x600)
  setrika.jpg    : foto setrika (800x600)
  bed-cover.jpg  : foto bed cover (800x600)
  login.jpg      : foto ruangan/aktivitas mitra untuk sisi kiri login
  status.jpg     : foto lipatan laundry untuk hasil cek status
  detail.jpg     : foto laundry untuk panel detail pengelola

Cukup TIMPA file gambar dengan nama sama. Tidak perlu membuka CSS/PHP!
File logo di situs saat ini adalah assets/images/logo/logo-mitra.jpg;
untuk ganti logo PNG, lihat file PANDUAN_GANTI_ASET.md.
Pakai foto yang memiliki izin dari mitra. Jangan unggah foto data pribadi pelanggan.
